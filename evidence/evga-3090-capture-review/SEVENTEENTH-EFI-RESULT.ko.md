# EVGA16 자산 및 소유권 결과

[English](SEVENTEENTH-EFI-RESULT.en.md) | [한국어](SEVENTEENTH-EFI-RESULT.ko.md)

EFI CPU 메모리에서 자산5개 읽기와 해시 검사가 모두 통과했습니다. GPU 드라이버 해제 후 공유 PCI 독점 획득 및 닫기에 성공했습니다. PROM 해시, 메모리 비활성화, 두 캡처 및 Windows 준비도 통과했습니다. 실패 보고가 없으면 정상 Windows 복귀를 가정합니다. [정리된 결과](seventeenth-efi-run-result.json), 원본 캡처는 로컬에 유지합니다. 잠금 해제나 DMA 작업은 실행하지 않았습니다.
