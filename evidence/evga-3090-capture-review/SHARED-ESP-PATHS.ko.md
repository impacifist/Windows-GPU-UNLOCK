# 공유 ESP: 읽기 전용 경로 검사

[English](SHARED-ESP-PATHS.en.md) | [한국어](SHARED-ESP-PATHS.ko.md)

공유 ESP 구현 전에 보고된 두 부팅 파일과 가능한 프로젝트 디렉터리 두 개만 기존 시스템 볼륨에서 검사합니다. 스크립트는 Windows에서 시스템 볼륨의 기존 경로를 조회하고 FAT32인지 확인한 뒤 파일 메타데이터/해시와 디렉터리 존재 여부를 검사합니다. 드라이브 문자를 할당하거나 파티션을 마운트하지 않고, 관련 없는 파일을 나열하거나 ESP에 쓰거나 부팅 구성을 변경하거나 재부팅하지 않습니다.

브랜치를 업데이트한 뒤 저장소 루트에서 PowerShell로 실행합니다.

```powershell
powershell -NoProfile -File ./research/profile/inspect-shared-esp-files.ps1
```

접근하려면 관리자 PowerShell이 필요할 수 있습니다. 볼륨 경로에 접근할 수 없으면 중단하고 오류를 보내 주세요. 공유 전에 JSON을 확인하세요. 고정된 EFI 경로, 파일 크기와 해시가 포함되지만 볼륨 GUID나 파일 내용은 출력하지 않습니다. 누락된 경로나 기존 프로젝트 디렉터리는 관찰 결과이며 덮어쓰기 권한을 의미하지 않습니다. 스크립트는 최종 경로의 예상하지 못한 개체 유형과 재분석 지점을 거부하지만 모든 상위 경로를 검증하거나 향후 쓰기 및 펌웨어 부팅의 안전성을 증명하지는 않습니다.

ESP를 사용하지 않은 시험 환경에서 존재/누락 파일과 디렉터리, 해시를 검사했습니다. 연구용 시스템의 시스템 볼륨이 FAT32로 보고되지 않아 실제 실행은 설계대로 거부됐으며 Movian의 시스템에서는 아직 접근하지 않았습니다.

이후 Movian은 읽기 전용 접근에 성공했다고 보고했습니다. Windows Boot Manager와 Limine 파일은 모두 존재했고 두 프로젝트 디렉터리는 검사 시 존재하지 않았습니다. 보고된 SHA-256은 각각 `2d60a2203865122dad22772136b3d905167d9dcf926d602bb5f48b3b6668abec`, `a11eea5e0235427a14f12035a1960c2659e0f0fd963092025719305ef542a462`입니다. 이는 기여자가 제공한 Windows 출력이며 펌웨어 로딩, 상위 경로 또는 쓰기 안전성 검증이 아닙니다.

이전에 제공된 EVGA19–EVGA23 캡처의 오프라인 그래프 검사에서는 완료된 각 캡처 두 개 모두에서 고정된 시스템 파티션의 GPT 장치 경로 노드와 Device Path 및 Simple File System 프로토콜 기록이 있는 핸들이 정확히 하나 발견됐습니다. 검사 도구는 모의 대상, 다른 GUID, 누락된 프로토콜 및 불완전 캡처 사례를 통과했습니다. 이는 기록된 USB 부팅 그래프를 재검토한 것이며 해당 볼륨에서 EFI 이미지를 로드할 수 있거나 이후 펌웨어 부팅에서도 같은 구성이 유지됨을 증명하지 않습니다.
