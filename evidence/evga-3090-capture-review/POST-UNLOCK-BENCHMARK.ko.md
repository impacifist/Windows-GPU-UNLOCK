# EVGA 잠금 해제 시도 후 벤치마크

[English](POST-UNLOCK-BENCHMARK.en.md) | [한국어](POST-UNLOCK-BENCHMARK.ko.md)

[EVGA19 트랜잭션 성공](EVGA19-RESULT.ko.md)과 Windows 자동 부팅 보고 후 Movian이 동일한 GEMM 벤치마크를 세 번 실행했습니다. 중앙값 TFLOPS:

| 작업 | 이전 | 이후 | 변화 |
| --- | ---: | ---: | ---: |
| FP32 pedantic | 26.379272 | 26.493910 | +0.43% |
| FP16 텐서 | 64.527754 | 122.869566 | +90.41% |
| BF16 텐서 | 64.558792 | 122.809845 | +90.23% |
| TF32 텐서 | 32.982266 | 64.157611 | +94.52% |

오프라인 비교 도구는 완료된 두 결과와 기록된 산출물, 런타임, 설정 및 시험 검사를 수락했습니다. 제공된 실행 후 빌드 매니페스트와 런타임 검증은 실행 파일 및 라이브러리 해시를 포함하여 두 실행에 기록된 정보와 정확히 일치합니다. Declan은 Movian이 설정 변경이 없다고 확인했다고 전달했으며, 확인 메시지 자체는 확인한 스레드에서 보이지 않았습니다. 런타임 검증의 `gpu_workload_run=false`는 사전 점검을 나타내며 세 번의 벤치마크 실행을 뜻하지 않습니다. 이 결과와 펌웨어 로그는 해당 시스템에서 텐서 GEMM 처리량이 증가했다는 강한 근거이지만, 단독으로 인과관계, 모든 작업의 성능 향상, 완전한 수치 정확성 또는 장기 안정성을 증명하지는 않습니다.
