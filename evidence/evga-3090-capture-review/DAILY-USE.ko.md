# 참석형 SharedEsp 일상 사용

[English](DAILY-USE.en.md)

이 안내와 저장소, `E:\UNLOCK\EVGA-PROFILE`, 원래 USB 및 기존 ESP 자산을 보존하세요. 상태를 옮기거나 삭제하지 말고 런처만 저장소 밖으로 복사하지 마세요. EVP11/EVP12에서 검증한 특정 장비 참석형 프로필이며 영구/무인 잠금 해제가 아닙니다.

## 더블클릭 준비

업데이트 후 저장소 안의 `research\profile\prepare-evga-unlock.cmd`에 대한 바탕화면 바로가기를 만듭니다. 대상 파일은 저장소에 그대로 둡니다.

1. 잠금 해제 세션이 필요할 때 원래 USB를 D:로 연결하고 준비 바로가기를 더블클릭한 뒤 일반 UAC를 승인합니다. 기존 보호된 Rearm 컨트롤러로 새 시도 빌드/검증, 슬롯 예약 및 일회 부팅 선택을 수행하며 자동 재부팅은 없습니다. 더블클릭/UAC 편의 래퍼 자체는 실제 검증 전입니다.
2. `prepared: true`일 때만 USB 제거/작업 저장 후 Shift를 누른 채 Windows 종료를 선택하고 전원을 켭니다. 실시간 검사 후 새로운 Shift+G를 한 번 누릅니다.
3. Windows에서 `research\profile\collect-evga-unlock.cmd` 또는 그 바로가기를 더블클릭하고 출력/ZIP을 보존합니다. 오류 시 무조건 반복하지 마세요.

준비는 로컬/ESP 파일과 일회성 펌웨어 변수를 씁니다. EFI는 기존 GPU/PCI 쓰기, DMA/펌웨어 및 리셋 위험을 유지하며 멈춤이나 Windows/GPU 실패 시 수동 전원 종료/정상 부팅 선택이 필요할 수 있고 복구는 보장되지 않습니다. UAC/실행 정책/검사 조건을 우회하지 않습니다. 거부 시 상태를 보존하고 오류를 보내세요. 소비 슬롯 재사용이나 자동 반복은 없습니다.

## USB가 필요한가요?

**EFI 실행/Windows 부팅에는 필요 없지만 준비에는 아직 필요합니다.** 현재 컨트롤러는 원래 USB에 영구 예약을 기록하여 과거 USB 흐름과 새 ESP 흐름이 같은 시도 번호를 재사용하지 못하게 합니다. 준비 후 USB를 제거하는 방식이 검증된 USB 없는 EFI 시험입니다.

준비 단계 USB까지 제거하려면 기존 런처 공존을 고려한 예약 기록의 별도 로컬 이전이 필요합니다. 파일 복사나 USB 검사 삭제만으로 대체할 수 없습니다. 런처에는 이 이전, 키 등록 또는 Secure Boot 지원이 포함되지 않습니다. 완료된 검증을 반복하려고 지금 실행할 필요는 없습니다.
