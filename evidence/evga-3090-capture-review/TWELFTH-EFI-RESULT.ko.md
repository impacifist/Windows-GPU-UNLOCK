# EVGA11 NVIDIA child release

[English](TWELFTH-EFI-RESULT.en.md) | [한국어](TWELFTH-EFI-RESULT.ko.md)

NVIDIA 자식 해제 단계에서 매우 좋은 결과입니다. EVGA11은 소비자 Stop6회 후 자식3개 Stop 한 번 성공과 후속 검사 통과를 기록합니다. 전체 그래프에서 정확히 자식 핸들3개가 제거되어549개에서546개가 되었고 추가 핸들은 없습니다. 가상 GOP만 남고 EDID-discovered 핸들은 없으며 부모 장치경로 자식 open은 제거되었습니다. NVIDIA PCI 소유권은 유지됩니다. 캡처2회 완료와 약간 더 긴 지연 후 자동 Windows 복귀가 보고되었습니다. 부모 해제와 언락은 미입증입니다. 해제 테스트 후 step4 언락 시도 전에 잠긴 상태 벤치마크를 저장하고 이후 같은 작업/설정을 반복해야 합니다.
