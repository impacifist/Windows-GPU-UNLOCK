# EVGA RTX 3090 기여자 캡처 검토

[English](README.en.md) | [한국어](README.ko.md)

이 별도 브랜치는 upstream main c403e8f0002ec69fc162a145d8172b2782ec9645에서 시작한다. 기여자는 ASUS Z790/i9-14900K/EVGA3090 구성을 보고했지만 보드/CPU 설명은 사용자 정보이며 파일로 독립 인증한 것은 아니다.

ZIP은50개 파일로 서로 다른426367바이트 진단2개, 로드 이미지46개,1MiB PROM, README를 포함한다. 두 진단은 capture-complete=1/diagnostic-result 성공을 기록한다. 오프라인 검사기는 NVIDIA 디스플레이1개220410de, subsystem33873842, GA102 b72000a1,24576MiB,0000:01:00.0을 식별한다. 다른 PCI 디스플레이는 없지만 GOP 핸들은2개다. PROM SHA256은 두 진단 기록과 일치한다.

현재 자동 로컬 프로필 경로는 두 자료를 topology_scope로 거부한다. 읽기 전용 직접 파서 검사는 첫 거부 원인을 확인한다. 통합 GPU가 관측되지 않는 경우 RTX가 그래프의 유일한 GOP를 소유해야 하는데2개를 발견했다. 실제 통합 GPU 부재나 두 번째 GOP 역할을 증명하지는 않는다. ConOut 변수 누락 기록도 있으며 후속 검사를 모두 수행한 것은 아니다. 거부를 우회하거나 다른 프로필을 복사하거나 GPU 모델만으로 잠금 해제 호환성을 추론하지 않는다.

[비공개 정보를 제외한 결과](capture-summary.json)는 해시와 검사 출력을 보존한다. 전체 진단/펌웨어 바이너리는 비공개 ignored 경로에 두며 압축 파일의 실행 코드는 실행하지 않았다. 서로 다른 해시만으로 별도 완전 종료 부팅이나 Windows 도착을 독립 증명할 수 없다. 검토 중 프로필 생성, 자산, GPU 쓰기, 펌웨어 실행, 잠금 해제 시험은 없었다.

다음은 기여자의 완전 종료 캡처2회와 Windows 결과 확인 후 두 GOP 장치 경로/소유 관계 및 콘솔 상태를 오프라인 검토하는 것이다. 토폴로지 확대는 별도 구현 검토와 재생 증거가 필요하며 이 결과만으로 쓰기 빌드를 허용하지 않는다.4070Ti 브랜치와 준비된 시험은 별도로 그대로 유지한다.
