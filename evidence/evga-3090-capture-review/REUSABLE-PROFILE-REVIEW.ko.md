# 재사용 프로필 기술 검토 — 2026-10-30

**검증 갱신:** [EVP11/EVP12에서 특정 장비 SharedEsp 검증을 완료했습니다](EVP12-RESULT.ko.md). 아래 초기 공유 패키지 시험 대기 설명을 대체합니다. 관리자 승인은 대기 중이며 Usb/SeparateEsp 재사용 패키지는 빌드/모의 검증만 완료했습니다.

[English](REUSABLE-PROFILE-REVIEW.en.md) · [사용 방법](REUSABLE-PROFILE.ko.md)

구현 검토는 완료했으며 관리자 승인과 새 패키지의 실제 장비 검증은 대기 중입니다. 기존 SULK02 증거는 해당 장비의 참석형 트랜잭션을 입증하며 새 설치 관리자나 모든 배치를 입증하지는 않습니다.

SharedEsp, Usb, SeparateEsp 프로필은 동일한 장비별 런타임 고정값과 새로운 Shift+G 입력 요구를 유지합니다. 일반 자동/무인 프로필 목록에는 포함하지 않습니다. SeparateEsp는 Windows와 다른 기존 내부 FAT32 ESP가 필요하며 파티션 생성이나 포맷을 하지 않습니다.

시도별 불변 기록, 패키지 목록/PE 검증, 볼륨 식별, 연속된 새 슬롯, 이전 증거 해시, 일회성 영수증, USB 로더 복원 및 정확한 소유 항목 정리를 검토했습니다. BootNext는 마지막에 선택하며 BootOrder는 쓰지 않습니다. 부분 실패는 상태를 보존하고 무조건적인 재준비를 거부합니다. 복구는 보장되지 않습니다.

## 실제 수행한 검사

- SharedEsp 10/11, Usb 8/9, SeparateEsp 8/9의 EFI 여섯 개를 컴파일했습니다. AMD64 EFI, import/IAT/delay import 없음, NX/dynamic-base를 확인했습니다.
- 세 배치의 호스트 미디어 허용/거부 검사와 영수증 게이트 여섯 사례가 통과했습니다.
- PowerShell 7과 Windows PowerShell 5.1에서 가짜 저장소/펌웨어로 실제 컨트롤러의 Install/WhatIf, 미완료 거부, 모의 실행, Collect/정리, Rearm 및 Cancel 경로가 통과했습니다.
- 두 셸에서 잘못된 패키지, 식별값, 이전 증거 변조, 펌웨어 경합 및 정리 정책 16개 검사가 통과했습니다.
- 기존 두 번째 shared 영수증 6개, 준비 8개, 펌웨어 선택/정리 32개 검사가 통과했습니다.

이 검사는 네이티브 펌웨어 API나 GPU에 접근하지 않습니다. 모의 환경의 소프트웨어 동작을 확인하며 실제 장비 성공을 의미하지 않습니다. 로컬 빌드는 `research/profile/build/reusable-v4`에 있으며 매니페스트에 소스 커밋, 변경 상태, 입력 해시와 파일 목록을 기록합니다. ZIP에는 펌웨어 자산을 재배포하지 않습니다.

## 관리자 검토 사항

병합 전 미디어 허용 조건, 출처 기록, 설치/정리 거부 조건과 기존 마커 공존을 검토해야 합니다. 첫 새 장비 시험은 SharedEsp 슬롯 10 설치, USB 없는 참석형 부팅, Windows 복귀, 수집 및 소유 항목 정리입니다. 이후 성공 실행의 재준비도 별도 실제 검증이 필요합니다. 별도 ESP 배치는 빌드/모의 검증만 완료했습니다. Secure Boot 서명/등록, 무인/영구 잠금 해제 및 다른 장비는 검증 범위 밖입니다.
