# EVGA 시도 전 벤치마크 기준

[English](BENCHMARK-BASELINE.en.md) | [한국어](BENCHMARK-BASELINE.ko.md)

Movian은 VS2019 Community 빌드와 메타데이터 사전 검사를 통과하고 3회 측정 결과를 업로드했습니다. 오프라인 load_run 검증에서 완료 해시, GPU/라이브러리/프로토콜, 4개 모드, 정확성 플래그, 샘플 설정 및 시간과 처리량의 일관성을 확인했습니다. 업로드된 컨텍스트에 아티팩트 해시와 런타임 정보가 포함되지만 별도 빌드 매니페스트/런타임 파일은 없었습니다. 해시는 기록된 출처이며 기여자의 실행 파일을 독립적으로 검사했다는 뜻은 아닙니다.

| 모드 | 중앙값 TFLOPS |
|---|---:|
| FP32 | 26.379272 |
| FP16 텐서/FP32 누산 | 64.527754 |
| BF16 텐서/FP32 누산 | 64.558792 |
| TF32 텐서/FP32 누산 | 32.982266 |

RTX3090, BDF0000:01:00.0, compute8.6, CUDA12.6/cuBLAS12.6, 드라이버621.01입니다. 기록된 전력 제한은420W, 최대 SM2100MHz, 메모리9751MHz이며 기본 설정 또는 실제 지속 클록이라는 주장은 아닙니다. 기존 실행 파일과 설정을 보존하고 실제 시도 이후 재빌드 없이 같은 실행기를 사용합니다. 완료 결과 폴더와 Windows 직접 복귀 여부를 보내면 여기서 비교합니다. 후속 측정 전 성능 향상을 주장하지 않습니다.

[정리된 데이터와 해시](benchmark-baseline.json). 원본은 Git에서 제외됩니다. 지금까지 잠금 해제 트랜잭션이 없었다는 근거의 시도 전 기준이며 하드웨어 잠금 상태를 독립적으로 인증하지 않습니다.
