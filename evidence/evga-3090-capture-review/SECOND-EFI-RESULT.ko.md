# 두 번째 EFI 실행: 캡처 완료 및 호출 전 미지원 검사

[English](SECOND-EFI-RESULT.en.md) | [한국어](SECOND-EFI-RESULT.ko.md)

Movian은 화면이 잠깐 나타났고 Shift+G를 누르기 전에 자동 Windows 부팅으로 이어졌다고 보고했습니다. 빌드/배치 출력은 19,456바이트 및 동일한 SHA256 8d19e2659328ef85d64ceacdd4680848d5be6fdf95865735cd85290a61161dd2입니다. EVGA01.TXT는 408,537바이트, SHA256 d743a246a38946fef7ad458a6142355cf2f6eec5a908377ce43f17a8fc09838c이며 원본은 로컬에 보존하고 [정제 결과](second-efi-run-result.json)에 식별자를 기록했습니다.

로그는 capture-complete=1 및 EFI_UNSUPPORTED(0x8000000000000003)의 evga-pre-stop-refusal-normal-windows를 기록합니다. Stop 전/반환 이벤트는 없습니다. 호출 전 정상 Windows 경로는 동작했지만 콘솔 제거 성공은 아닙니다. 소스상 인벤토리 또는 초기 그래프 검사가 G 입력 대기 전에 거부했으며 이전 빌드는 구체적 검사를 기록하지 않았습니다. 정확한 거부 원인은 미해결입니다. 기록된 PCI ID/서브시스템, 콘솔 형태, 드라이버 크기/버전/Stop RVA는 이전 캡처와 일치하지만 모든 실시간 API/코드 검사의 성공을 증명하지는 않습니다.

새 이미지는 각 인벤토리/소유/코드 검사 결과와 바인딩 버전, 이미지 크기, Stop RVA를 기록하며 로드 주소는 기록하지 않습니다. 코드 실패는 바인딩/로드 이미지/Stop 주소 단계를 구별합니다. 검사를 완화하지 않았습니다. 파일을 닫은 뒤 최종 검사는 로그를 호출하지 않습니다. G 프롬프트는 실시간 검증 성공 후에만 `Live guards passed. NOW press fresh Shift+G once`로 표시됩니다. Stop 전 거부는 정상 Windows 시작을 시도하고 Stop 시작 후 실패는 여전히 정지합니다.

검증: 최종 검사 로그 호출 없음 확인을 포함한 호스트 체크포인트 18개, 캡처 경로 회귀 9개, Python 테스트 78개 통과입니다. 경고를 오류로 처리하는 EFI 빌드와 PE 검사도 통과했습니다. 새 로컬 파일은 20,992바이트, SHA256 d01da964d90279b84b902dfa6c493f1091b9944a8af85b6df4aa2d62b4db92ce입니다. 도구 체인에 따라 해시는 달라질 수 있으므로 본인 매니페스트와 배치를 비교합니다.

다음은 GitHub Desktop 업데이트 후 같은 명령으로 재빌드/배치하고 동일한 참석형 1회 호출 테스트입니다. 새 GPU 주소/리셋/펌웨어 업로드/PCI 쓰기/추가 Stop은 없습니다. 다시 거부하면 다음 로그로 검사 단계를 확인하며 강제 우회하지 마세요. 기존 로그/백업/마커를 보존하고 다음 EVGAnn.TXT 및 자동/수동 Windows 복귀를 보내주세요. 기존 위험이 적용되며 별도 확인 답변은 필요 없습니다.
