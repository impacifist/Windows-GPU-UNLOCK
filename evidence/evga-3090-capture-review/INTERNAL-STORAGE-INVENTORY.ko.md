# EVGA 내부 부팅: 읽기 전용 저장소 조사

[English](INTERNAL-STORAGE-INVENTORY.en.md) | [한국어](INTERNAL-STORAGE-INVENTORY.ko.md)

검증된 EVGA 프로필은 현재 USB를 사용합니다. 별도의 내부 런처는 다른 시스템용이므로 그대로 사용할 수 없습니다. EVGA 내부 경로를 설계하기 전에 이 조사는 부팅 설정 변경, 파티션 마운트 또는 포맷, 디스크 쓰기 없이 저장소 구성과 기존 전용 EFI 파티션 후보를 식별합니다.

업데이트한 브랜치의 저장소 루트에서 실행합니다.

```powershell
powershell -NoProfile -File ./research/profile/inspect-internal-storage.ps1
```

JSON에는 디스크 번호, 버스 유형, 파티션 크기/유형, 드라이브 문자 및 파일 시스템이 포함됩니다. 디스크 일련번호와 파티션 GUID는 제외됩니다. 공유하기 전에 내용을 확인하고 출력 또는 오류를 보내 주세요. `candidate_dedicated_esp`는 시스템 또는 부팅 파티션이 아니고 드라이브 문자가 있는 1 GiB 이상의 비 USB FAT32 GPT EFI 파티션 후보일 뿐입니다. 파티션이 사용되지 않거나 쓰기에 안전하거나 펌웨어에서 접근 가능하거나 EVGA 프로필에 적합하다는 보장은 아닙니다. 드라이브 문자가 없는 EFI 파티션은 후보로 식별되지 않습니다. 후보가 없어도 파티션 변경을 승인하는 것은 아닙니다.

로컬 검증: 모의 시스템/전용/USB 사례와 연구용 시스템의 읽기 전용 조사를 통과했습니다. 이 단계에서는 실제 EVGA 내부 부팅 구현이나 설치를 하지 않습니다.

Movian이 제공한 조사 결과에는 약 10.9 GiB 크기의 Windows 시스템 EFI 파티션 하나가 있으며, 현재 조건을 충족하는 별도 후보는 없습니다. 이 조사에서 시스템 EFI의 드라이브 문자와 파일 시스템은 표시되지 않으므로 내용과 여유 공간은 알 수 없습니다. Linux 데이터 파티션은 EFI 후보가 아닙니다. 현재 별도 파티션 내부 부팅 코드는 자체 볼륨과 Windows 파티션이 같으면 실행을 거부하며 EVGA 빌드는 현재 USB 매체를 요구합니다. 시스템 파티션 크기만으로 이 프로필에 사용할 수 있다는 뜻은 아니며 파티션 변경이나 설치를 의미하지 않습니다.

Movian은 Windows와 CachyOS 이중 부팅을 위해 ESP를 확장했으며 기존 ESP에 별도 부팅 항목을 추가하는 방식을 선호한다고 보고했습니다. 공유 ESP 경로에는 EVGA 전용 설계가 필요합니다. 실제 로드된 파티션을 고정하고 검증하며 런처, 자산, 캡처와 마커를 별도 경로에 보관하고 기존 Windows/Linux 파일을 덮어쓰지 않아야 합니다. 또한 별도 ESP 검사가 이 구성에도 적용된다고 가정하지 않고 선택된 부팅 인계와 부팅 항목 복구를 검증해야 합니다. 현재 코드는 고정된 Windows Boot Manager를 미리 로드하므로 잠금 해제 후 CachyOS 선택이 유지된다는 뜻은 아닙니다. 기존 조사와 USB 성공만으로 여유 공간, 내용, 펌웨어 정책, 공유 ESP 안전성 또는 무인 동작은 입증되지 않았습니다. 이 경로에 대한 재분할, 설치, 펌웨어 부팅 항목 변경 또는 하드웨어 시험은 수행하지 않았습니다.
