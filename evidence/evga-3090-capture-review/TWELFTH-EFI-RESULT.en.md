# EVGA11 NVIDIA child release

[English](TWELFTH-EFI-RESULT.en.md) | [한국어](TWELFTH-EFI-RESULT.ko.md)

A great NVIDIA child-release milestone: EVGA11 records one successful three-child Stop after the six consumer Stops and passing postchecks. Complete graph comparison finds exactly three child handles removed (549 to546), no handles added, only the virtual GOP remaining and no EDID-discovered handles. The parent device-path child opens are gone; NVIDIA PCI ownership remains. Both captures complete and the operator reports automatic Windows return after a longer delay. Parent release and unlock remain unproven. A locked-state benchmark is required after release testing and before step4, the unlock attempt; repeat identical workload/settings afterward.
