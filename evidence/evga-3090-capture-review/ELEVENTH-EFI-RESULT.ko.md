# EVGA10 NVIDIA preflight

[English](ELEVENTH-EFI-RESULT.en.md) | [한국어](ELEVENTH-EFI-RESULT.ko.md)

EVGA10은 소비자 Stop6회 전후의 NVIDIA 코드/PCI 소유자/자식3개/private 인터페이스 검사를 통과했습니다. 저장 자식 분류1은 물리 GOP이며 부모 flag98은0으로 전후 유지됩니다. 캡처2회 완료 및 이전과 같은 자동 Windows 복귀가 보고되었습니다. 분기별 사전 검사 증거이며 NVIDIA 해제나 언락 증거는 아닙니다.
