# EVGA22 재준비 프로필 결과

[English](EVGA22-RESULT.en.md) | [한국어](EVGA22-RESULT.ko.md)

Movian은 EVGA21을 기반으로 다음 번호의 시도를 준비한 뒤 EVGA22와 슬롯 6 마커를 제공했습니다. 캡처에는 슬롯 06, 승인, FLR 전후 예상 선택자, 트랜잭션 결과 0, 기록된 오류 없음, 정지된 리소스, 남은 매핑 없음, 자산 정리, 완료된 캡처 2개 및 Windows 준비 성공이 기록됐습니다. FLR 후 SS1 값은 로그 두 줄에 걸쳐 있습니다. 로그만으로 Windows 시작이나 실행 후 성능을 독립적으로 증명할 수는 없습니다.

이는 슬롯 5 이후 두 번째 번호 지정 시도가 실제 시스템에서 트랜잭션을 완료했다는 근거입니다. 무인 또는 내부 부팅, 절전/재시작 동작 또는 장기 안정성을 증명하지는 않습니다. 업로드된 원본 캡처는 비공개입니다. SHA-256: `9d03698bca6768f5771e0a45c80d26f3978a2c30f923ee712f118f2b6790160b`.
