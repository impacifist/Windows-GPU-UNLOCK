# EVGA 프로필 배포 상태

**현재 상태, 2026-10-30:** 특정 장비의 재사용 SharedEsp 검증을 완료했습니다. EVP11 트랜잭션/같은 세션 벤치마크/정리/일반 부팅과 EVP12 기본 재준비/트랜잭션/수집/정리가 확인되었습니다. [최종 결과와 전달](EVP12-RESULT.ko.md). 관리자 승인은 대기 중입니다. Usb/SeparateEsp 프로필은 존재하지만 새 재사용 패키지는 빌드/모의 검증만 완료했습니다. 이번 검증 순서에 추가 EFI를 요청하지 않습니다. 아래 과거의 대기 상태 설명은 이 현재 상태로 대체합니다.

## 입회 SULK02 증거 완료 — 2026-10-30

검토된 EVGA RTX 3090/Z790 장비가 USB 없는 펌웨어 진입, 새 Shift+G 잠금 해제, 정상 Windows 복귀, 같은 세션 벤치마크, 임시 항목 정리 및 Boot0000을 통한 이후 정상 재시작을 완료했습니다. 임시 항목은 계속 없고 BootNext도 없으며 주 Limine/Windows 항목은 변경되지 않았습니다.

로그는 슬롯 9, 성공한 반환, 자산 해제와 캡처 2회를 기록합니다. 벤치마크 완료/프로토콜/시간 검사가 통과하고 기록된 기준 문맥이 일치합니다. FP16 +91.00%, BF16 +91.08%, TF32 +94.53%, FP32 대조군 +0.42%입니다. USB 미연결, 측정 전 재부팅 없음 및 정상 Windows 동작은 기여자가 확인했습니다. [증거 요약](sulk02-result.json) · [벤치마크 검토](sulk02-benchmark.json) · [전체 결과](SULK02-RESULT.ko.md).

정리는 저장된 속성 7로 Boot7E00만 삭제하고 BootOrder는 쓰지 않았습니다. 일반 대체 항목 3개가 그전에 사라진 원인은 알 수 없으며 복원하지 않았습니다. 이후 정상 부팅 확인은 펌웨어 쓰기나 GPU 접근 없이 완료되었습니다. 이번 복귀 성공이 다른 환경의 복구를 보장하지 않습니다.

## 검토 가능한 범위

정확한 해당 장비의 입회 구현, 증거, 성능 비교, 일회용 영수증/예약, 진단/거부 처리, 수집 및 제한된 정리가 관리자 검토 가능한 상태입니다. 로컬 모의 검사는 관련 스크립트와 실패 시 중단을 검사하며 정상 부팅 검사는 PowerShell 7/Windows PowerShell 5.1에서 통과했습니다. 실제 기여자 증거와 구분합니다.

완료된 SULK02 순서에 추가 하드웨어 시험을 요청하지 않습니다. 원본 USB 예약, ESP 영수증/로그, 복사한 EFI 및 비공개 펌웨어 백업을 보존하고 게이트 삭제나 소비된 슬롯 재실행을 하지 마세요.

## 남은 소프트웨어/배포 작업

재사용 설치/재준비 인터페이스는 완성되지 않았습니다. 현재 개발 명령은 검토된 슬롯, 고정 SULK02 파일명, 정확한 해시 및 장비 하나에 묶여 있습니다. 다음 시도는 새로 검증한 슬롯/빌드가 필요하며 SULK02를 재사용하면 안 됩니다. 영구/무인 잠금 해제, 일반 재부팅 후 유지, 다른 펌웨어 구성이나 GPU는 이번 증거로 확인하지 않았습니다. 재사용 포장과 관리자 검토 후에만 일반 운영 프로필로 부르세요. 4070Ti 연구는 별도입니다.

## 재사용 패키지 구현 완료 — 2026-10-30

위의 패키지 미완료 설명은 현재 상태로 대체합니다. SharedEsp, Usb, SeparateEsp 프로필과 설치/수집/재준비를 구현하고 로컬 검증했습니다. [사용 방법](REUSABLE-PROFILE.ko.md)과 [기술 검토](REUSABLE-PROFILE-REVIEW.ko.md)를 참고하세요. 새 패키지의 실제 장비 검증과 관리자 승인은 대기 중이며 특정 장비용 참석형 개발 프로필입니다.
