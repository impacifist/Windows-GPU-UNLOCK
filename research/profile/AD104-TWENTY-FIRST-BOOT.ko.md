# 21차 참석 후보: 전체 PROM 캡처와 검증 결합

실행 결과: [21차](AD104-TWENTY-FIRST-RESULT.ko.md). 아래는 원래 후보 계약입니다.


[English](AD104-TWENTY-FIRST-BOOT.en.md) | 한국어

빌드·호스트 검사 완료, 실제 실행 전입니다. 확대 MMIO의 별도 승인이 필요합니다.
[20차](AD104-TWENTIETH-RESULT.ko.md)는 실제 PROM 앞부분512바이트와 직접 복귀만 입증했습니다.

## 결합 순서

1. 기존 다섯 중지, Enable(0x300), 시간차 레지스터 배치와512바이트 헤더를 수행합니다.
2. PROM.BIN 부재 확인,2MiB RAM(캡처/재읽기 각 절반) 할당, intent flush 후
   PCI/속성/BAR/소유권/이전 자식 부재 전체 상태를 새로 검사합니다.
3. BAR0 0x300000–0x3ffffc의 고정1MiB를262,144DWORD로 한 번 읽습니다.
   이 시퀀스에 파일·콘솔·할당 콜백은 없지만 PCI Mem.Read 자체는 부작용/hang이
   있을 수 있습니다. 일반 데이터FFFFFFFF/BADF는 허용하고 전송 오류/메서드 변경은
   중지합니다. 첫 DWORD 및 전체 첫512바이트는 같은 부팅에서 검증한 앞부분과 같아야 합니다.
4. 서명/chip과 전체 상태를 재검사하고 파일 작업 전 RAM 캡처 해시를 계산합니다.
   부재를 다시 확인한 뒤 빌린 실행 볼륨 root에서 새 PROM.BIN만 생성합니다.
   root/log/witness 별칭을 거부하고 정확한1MiB 쓰기·flush·seek0·1MiB 재읽기·EOF·
   변경 불가 원본 해시 일치·Close 성공을 요구합니다. 기존 파일은 덮어쓰지 않습니다.
5. 버퍼 해제 후 상태 재검사, 전송 완료와 최종 상태 허용을 구분해 기록하고 로그
   콜백 뒤 재검사합니다. 실패 시 부분 파일은 불완전 증거이며 재시도/덮어쓰지 않습니다.
6. 새 V와 최종 검사 후 기존 Disable(0x300) 한 번, 부모 중지 직후 전체 상태 반복
   검사, 독립 STATUS.TXT 및 Windows 복귀를 수행합니다.

성공 경로는 PROM DWORD 접근262,274회(헤더129+전체262,144+서명1), chip 재확인2회,
기존 레지스터44회로 총 Mem.Read262,320회입니다. MMIO 범위와 노출 시간이 늘어납니다.
두 번째 전체 캡처·펌웨어 실행/업로드·리셋·재연결·BME/VGA 활성화·unlock은 없습니다.
실패 시 자동 rollback 없이 정지하고 화면/입력/Windows가 실패할 수 있어 수동 전원
종료/USB 제거가 필요할 수 있습니다. 이 후보의 복구는 미입증입니다.

1MiB 전송 완료가 모든 바이트의 유효 ROM 여부, 전체 이미지 체인·체크섬·FWSEC를
증명하지는 않습니다. 복귀 후 오프라인 파싱/비교를 수행합니다. SS1/VGA_BASE 차이도 남습니다.

## 검증과 실행 시간 안내

호스트 mock은 연속 범위, 앞부분/서명/chip/메서드 오류, 첫/중간/마지막 전송 오류,
정상 sentinel 데이터, 할당, 파일 별칭, 짧은 쓰기/읽기, EOF, 원본/재읽기 손상,
seek/flush/close/free 오류 및 콜백에 의한 PCI 변화를 검사합니다. 반복 검증 수백만 번이
서로 독립적인 시험 수백만 개라는 뜻은 아닙니다. 기존 헤더/수명주기/복귀 검사도 유지합니다.
호스트 검사는 실제 안전성을 입증하지 않습니다.

Native58,368바이트 AMD64 PE/import 없음, SHA-256은
`60b258feb75a2b967ef93b5231e89a5e6786e97304b2b61c9687798e860b1ae0`입니다.
Ad104PromFullTest는 헤더/시간차/decode-off/read를 요구하고 manifest는 캡처1,048,576바이트와
헤더512바이트를 고정합니다.

승인·준비 후 작업 저장, 완전 종료,10초 대기, UEFI USB 부팅. Shift+G로 전체 허용.
10초 후 Shift+V를2초마다 최대3분 누릅니다.3분은 사용자 입력 안내이며 펌웨어의 내부
대기 시간은 검사 완료 뒤60초입니다. 해제 후 화면 업데이트나 신뢰할 실시간 진행 표시는
없습니다.10분 안에 Windows가 없으면 전원 종료, USB 제거 후 정상 Windows Boot Manager를
선택합니다. 펌웨어 콜백의 완료 기한은 보장되지 않습니다. 한 번만 실행하고 재시도 전에
PROM.BIN/STATUS.TXT를 포함한 캡처를 전달하십시오.
