# 열세 번째 AD104 시험: PCI 소유자 Stop 직접 호출

실행 결과: [13–18차 및 복구 결과](AD104-THIRTEENTH-EIGHTEENTH-RESULT.ko.md). 아래 계약은 원래 13차 후보를 설명합니다.


[English](AD104-THIRTEENTH-BOOT.en.md) | 한국어

상태: 빌드와 호스트 시험 완료, USB 준비 및 실제 실행 전입니다.
[열두 번째 결과](AD104-TWELFTH-RESULT.ko.md)의 네 단계 뒤에 다섯 번째 단계를
추가합니다. 정확히 고정한 IMG29의 `Stop(binding, gpu, 0, NULL)`을 한 번 호출합니다.
드라이버는 PCI I/O/메모리 디코딩, 버스 마스터링 및 VGA 속성을 비활성화할 수
있습니다. 응용 프로그램의 명시적 속성 쓰기, 디코딩 재활성, 재연결, 리셋,
GPU MMIO, FWSEC 트랜잭션, 펌웨어/NVRAM 쓰기 또는 unlock은 포함하지 않습니다.

호출 전 두 번의 새 관측이 자식 Stop 성공 상태와 일치해야 합니다: 세 관계,
이전 자식 핸들 없음, command7, 속성718/지원1b77b, 공유 바이트0/포인터1/1,
전체 PCI/BAR/PCD/입력 유지 및 정확한 코드/바인딩 지문. IMG29 RVA39d0의 분기 GUID는
`c7735a2f-88f5-4882-ae63-faac8c8b86b3`여야 하고 이 프로토콜은 GPU에 없어야 합니다.
존재, 예상하지 않은 오류 또는 NULL이 아닌 결과는 거부합니다. 바인딩 인스턴스와
분기 부재를 포함해 의도 기록 flush 후 다시 검사합니다.

캡처한 정적 경로는 Supported 질의, Disable `(Supported & 0x700) | 0x18`
(예상718), PCI BY_DRIVER 닫기를 수행합니다. 드라이버가 중간 반환값을 전부
검사하지 않으므로 콜백 성공만으로는 부족합니다. 실제 검증이 필요한 예측입니다.

두 번의 새 사후 수집에서 포인터 두 관계만 남고 이전 자식 부재, command0,
속성0, 지원1b77b 및 나머지 상태 유지가 필요합니다. PCI status 상위16비트도
유지해야 합니다. 자식 제거 후 오류 시에도 저장한 GOP/mode나 이전 자식 프로토콜에
접근하지 않습니다. 콜백 오류나 예상하지 않은 상태는 재시도/복원 없이 정지합니다.
사후 검사, 새 대문자 V, 최종 상태 및 로그 닫기가 모두 성공해야 미리 로드한
Windows 부트 매니저를 시작합니다. command0/BME 비활성도 보호 메모리/cold-entry
허용 조건을 입증하지는 않습니다.

새 위험 경계: 실제 PCI 소유자를 정지시키고 드라이버가 디코딩과 DMA 권한을
제거하도록 합니다. 화면/입력 손실, 펌웨어 정지, Windows GPU 초기화 또는 부팅
실패가 가능하며 수동 전원 차단/USB 제거가 필요할 수 있습니다. 자동 복원은
시도하지 않습니다. 이전 자식 전용 성공은 이 상태의 복구를 입증하지 않습니다.
USB 준비 전에 이 경계 수락이 필요합니다. 아직 부팅하지 마세요.

직접 부모 RAM 검사336개는 콜백 오류/부분 변경, 남은 소유권, 무효/잔여 속성,
잘못된 command/status/BAR, 포인터/입력 변경, 자식 재등장, 의도/최종 기록 실패,
바인딩/분기 변경 및 최종 키 변경을 포함합니다. 실제 분기 도우미는 GUID 바이트,
범위, 존재와 정의된 부재 상태를 별도로 시험하며 전체 엔진 모의 시험은 그 결과를
모델링합니다. 준비 시험과 Python33개가 통과했습니다. 네이티브 AMD64 EFI48,128
바이트는 import/IAT/delay import 없음 및 NX/dynamic base 검사를 통과했습니다.
SHA-256: `c148f2c09282c4afeaf77e9d8ade33f0551aab2bb064991c2f2dbf11966bfc0c`.
호스트 시험은 실제 복구 증거가 아닙니다.

수락 및 USB 준비 확인 후: 완전 종료,10초 대기, ASUS Delete/F8 → UEFI USB DISK2.0.
Shift+G 한 번으로 다섯 단계를 허용하고5초 뒤 최대1분간2초마다 Shift+V를 누릅니다.
두 번째 안내는 없습니다. 한 번만 부팅하세요. 정지 또는5분 후 Windows가 없으면
전원 차단/USB 제거 후 일반 Windows Boot Manager를 선택합니다. 복구는 미입증입니다.
재시도 전에 캡처를 보관해야 합니다.
