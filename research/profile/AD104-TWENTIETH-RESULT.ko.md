# 20차 결과: 실제 PROM 앞부분 캡처 및 Windows 복귀

[English](AD104-TWENTIETH-RESULT.en.md) | 한국어

2026-10-27 MSI RTX4070Ti AD104에서 실제 BAR0 PROM 앞부분128DWORD/512바이트를
모두 캡처했습니다. 서명/chip 재확인, 제한된 PCIR 파싱, 상태 검사, decode-off와
복귀 허용 검사를 통과했습니다. 사용자는 Windows 자동 시작을 확인했고 root/main-log
Close도 성공했습니다.

PCIR 오프셋은368, vendor10de/device2782이며 첫 이미지 길이는64,512바이트입니다.
캡처512바이트는 이전150,016바이트 펌웨어 RAM ROM의 첫512바이트와 정확히 같습니다.
앞부분 SHA-256은
`7860719945ae7f43fc7a565551c97788176d6113384068f2ea0c3e52beb130ee`입니다.
이는 앞부분 동일성만 뜻하며 전체 ROM 동일성, 체크섬/체인, FWSEC, unlock 허용/실행을
검증하지 않습니다. 서명 재확인만으로 모든 앞부분 바이트의 시간적 안정성도 증명하지 않습니다.

35개 원본/사본 파일은 SHA-256 검증 후 비공개 보관했습니다. 로그128개 오프셋의
연속성을 확인한 뒤에만 앞부분 파일을 재구성했습니다. [정제된 증거](ad104-twentieth-boot-evidence.json)는
해시/메타데이터를 담고 원본 ROM과 플랫폼 식별자는 공개하지 않습니다.

다음 결합 후보는 고정1MiB 창 캡처, 같은 부팅의 앞부분·서명·chip·상태 검사,
PROM.BIN 파일 재읽기/해시 검증과 기존 decode-off 복귀를 수행합니다. 확대된 MMIO의
별도 승인이 필요합니다. 캡처 후 오프라인 ROM 체인/FWSEC 파싱을 수행할 계획이며
앞부분만으로 이를 주장하지 않습니다.
