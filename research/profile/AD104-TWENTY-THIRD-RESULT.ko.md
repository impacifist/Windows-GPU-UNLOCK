# 스물세 번째 결과: RAM 리허설과 Windows 복귀 통과

[English](AD104-TWENTY-THIRD-RESULT.en.md) | [한국어](AD104-TWENTY-THIRD-RESULT.ko.md)

2026-10-27 테스트23에서 FWSEC 메모리 복사본 패치 통합이 통과했습니다. 로그의 source-unchanged, patch-match, selector-matrix, scratch-intact는 모두1입니다. 허용된48바이트 범위에서 정확히9바이트가 변경됐습니다. 패치 RAM SHA-256은 호스트 리허설과 같습니다:
`0bca65c5d5f41cec855acd8009340a86a1e08d117cb9c1a716cb444f3d0a2d52`.

1MiB PROM은 테스트21/22와 동일합니다:
`accf2a054de0ec394078f933f74356ed7c4057ee0bd1ce6734cacda54ca9e1e1`.
전송, 메모리 해제, 최종 상태, 디코딩 해제 및 Windows 진입 검사가 성공했습니다. STATUS는 루트/로그 닫기와 StartImage-next 성공을 기록하며 사용자는 Windows 자동 복귀를 확인했습니다.36개 파일을 비공개로 복사해 원본/복사본 SHA-256을 모두 검증했습니다. Windows에서 RTX4070Ti와 드라이버610.88을 확인했으며 이번에는 워크로드를 실행하지 않았습니다.

EFI RAM 준비와 복구 통합을 검증한 결과입니다. FRTS 주소는 가상 값이며 실제 퓨즈 읽기, 펌웨어 업로드/실행은 없고 권한은0입니다. 가상 서명 인덱스는 인증을 입증하지 않습니다. 체크리스트는15/26(58%)입니다.

다음 유용한 작업은 SS1/VGA/BAR 차이, 정확한 장치 진입 정책 및 자산 적합성의 오프라인 조사입니다. 동일 부팅 반복으로 해결되지 않습니다. 펌웨어 실행은 별도 승인이 필요한 하드웨어 경계입니다. 이번 결과 업데이트에서는 새 EFI를 스테이징하지 않았으며 USB에는 실행한 테스트23과 원본 캡처가 남아 있습니다. 보존/재스테이징 전 다시 실행하지 마십시오.
