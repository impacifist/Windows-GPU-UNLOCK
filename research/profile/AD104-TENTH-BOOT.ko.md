# 열 번째 AD104 부팅: 텍스트 후 그래픽 콘솔 소비자 해제

[English](AD104-TENTH-BOOT.en.md) | 한국어

아홉 번째 실행은 텍스트 해제와 PCD 제공자 캡처를 입증했다. 이번에는 보호된
텍스트 단계를 반복하고 새 IMG17 GOP 소비자 해제를 한 번 허용한다.
**PCI 소유자와 그 GOP 인터페이스는 유지한다.** EDID/포인터 소비자도 유지하며
unlock, 속성 쓰기 또는 GPU MMIO는 포함하지 않는다.

## 허용 조건 및 순서

기준 수집은 비공개 `PCDPROD.BIN`을 다시 저장한다. 아홉 번째의 캡처, 코드/
바인딩, 목록/캐시, 조건 및 화면 상태 검사를 유지한다. PCD 제공자는 이제
아홉 번째 실행 코드 지문에도 일치해야 한다. RVA `0x2a0`, 길이 `0x236d`, SHA-256
`cb64fe58020cf7512de99c86d8284baca00dd679109680ea1af371081e3b6367`이다.
해당 코드 범위에는 재배치 대상이 없다. 검토한 접근자 모듈의 코드 지문이며
데이터베이스 헬퍼 전체 검토는 아니다. 같은 실행의 전체 이미지 일관성 검사도 유지한다.

대문자 `G` 한 번이 두 단계를 허용한다. 텍스트 해제가 여덟 관계에서 여섯 관계,
빈 목록, PCD 캐시 및 화면/구성 사후 조건을 먼저 통과해야 한다. 이후 새 단계는
자식의 SimpleTextOut과 동반 프로토콜
`e1e4a857-c970-4075-a4da-e9c41b69adfc`를 확인한다. 인터페이스는 IMG17 제거
호출에서 확인한 `text + 0x101` 관계여야 하며 두 사전 검사 사이 식별 정보도
같아야 한다. 아홉 번째 그래프는 두 프로토콜의 존재를 확인했지만 인터페이스
값 자체는 기록하지 않았다.

별도 두 번째 실행 의도를 flush하고 여섯 관계 및 프로토콜 식별 정보를 새로
검사한 뒤 정확히 한 번 호출한다.
`DisconnectController(discovered_gop_child, exact_img17_binding, NULL)`.
대상은 그래픽 콘솔 소비자이며 PCI 소유자나 모든 드라이버가 아니다. 애플리케이션은
첫 텍스트 시도 이후 조용히 동작한다. IMG17 호출 후 저장된 자식 텍스트
인터페이스/모드는 이미 해제되었을 수 있으므로 역참조하지 않는다.

호출 성공/오류와 관계없이 독립 사후 상태 두 개와 프로토콜 부재를 수집한다.
필수 조건은 다음과 같다.

- 관련 관계 다섯 개: IMG17 GOP open만 추가로 제거됨.
- 자식에서 SimpleTextOut과 동반 프로토콜 모두 부재.
- 소유자 GOP 인터페이스/메서드/모드/정보/프레임버퍼 메타데이터, 전체 PCI 구성,
  BAR 및 속성 `718`/지원 `1b77b` 불변.
- EDID/포인터 관계와 IMG08 `1/1/1` 유지, 텍스트 목록 비어 있음, PCD 캐시 일치.
- 고정한 코드, 제공자 일관성과 새로 확인한 false PCD 조건 유지.

조용한 실제 `V` 입력과 새 다섯 관계/프로토콜 부재 검사를 수행한다. 이후 기록과
파일 닫기가 성공해야 Windows로 인계한다. IMG17은 여러 정리 결과를 무시하므로
콜백 성공만으로 전이를 허용하지 않는다. 분석한 Stop에 직접 SetMode/Blt 호출은
없지만 펌웨어를 통한 영향이나 일시적인 화면 효과를 배제할 수는 없다.

어떤 실패도 재시도, 재연결, 복원, 재부팅 또는 BootOrder 대체 부팅 없이 정지한다.
각 단계는 한 번만 실행한다. 캡처 또는 텍스트 성공으로 실패한 GOP 단계를
건너뛸 수 없다. 예상 출력은 로그, 드라이버 덤프 32개와 PCD 제공자 등 비공개 34개다.

## 운영자 지침

1. 작업을 저장한다. USB 연결 상태에서 `shutdown /s /t 0`, 전원 종료 후 10초
   대기, ASUS Delete → F8 → **UEFI: USB DISK 2.0**(8GB)을 선택한다.
2. 첫 안내에서 **Shift+G**를 한 번 눌러 텍스트 후 GOP 소비자 해제를 허용한다.
   다른 키나 시간 초과는 테스트를 정지한다.
3. 5초 기다린 뒤 Windows가 시작될 때까지 **Shift+V를 2초마다 짧게 누른다**.
   최대 1분이며 키를 누른 채 유지하지 않는다. **두 번째 안내는 없다.**
4. 정지하거나 Windows가 5분 안에 복귀하지 않으면 전원을 끄고 USB를 제거한 뒤
   일반 Windows Boot Manager를 선택한다. 한 번만 부팅하고 결과를 보존한다.

화면/입력 손실, 펌웨어 정지, Windows 복귀 실패가 가능하다. 내장 GPU가 없으며
아홉 번째의 복귀가 새 두 번째 해제의 복구를 입증하지는 않는다. 60초 입력
폴링 예산은 멈춘 펌웨어 콜백을 중단할 수 없다. 5초는 운영자 대기 지침이다.

구현 `5e3af5f`, EFI 43,520바이트, SHA-256
`3cb4550e4760c722b3f5bb03846f337e2d61a423ecd813694729de8a2dd02e22`.
아홉 번째 빌드 옵션에 `-Ad104GopTest`를 추가한다. CanDetach/CanReleaseGopConsumer는
true, CanReleasePciOwner/CanUnlock/CanReadGpuMmio는 false다. AMD64 PE 검사에서
import/IAT/delay import 없음과 NX/dynamic base를 확인했다. RAM 검사 통과 수는
GOP 수명 주기 112, 텍스트 139, 제공자 53, 화면 29, 조용한 인계 21과 기존 검사다.
잘못된 컴파일 조합 27개를 거부했으며 Python 31개도 통과했다. 소프트웨어 검증이며
실제 GOP 해제 증거는 아니다. 준비 전에 아홉 번째 캡처/EFI를 호스트와 USB에 보존한다.
