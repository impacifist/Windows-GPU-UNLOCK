# AD104 오프라인 소유권 분석 결과

[English](AD104-OWNERSHIP.en.md) | 한국어

첫 부팅의 비공개 보관 자료를 펌웨어 이미지 실행이나 GPU 접근 없이 분석했습니다.
[재현 가능한 증거](ad104-ownership-evidence.json)에는 이미지 해시와 역할별
연결만 기록하고 주소와 원본 이미지는 제외했습니다.

## 확인한 관계

정확한 AD104 PCI 핸들의 PCI I/O에는 `BY_DRIVER` 열기 기록이 있습니다.
동일한 에이전트가 GOP를 노출하는 핸들을 가리키는 `BY_CHILD_CONTROLLER` 기록도
가집니다. 해당 드라이버 바인딩은 `IMG29.BIN`(18,432바이트)에 연결됩니다.
SHA-256은 `6978c561cfc119be29c3832d47fc51e471b02e86dc84b3a4eac6524a65de502c`입니다.
이는 관찰된 PCI-to-GOP 소유 관계를 입증하지만 공급업체 ID나 안전한 드라이버
중지 순서를 입증하지 않습니다. 이미지의 UTF-16 이름 `BIOS[INT10] Video Driver`는
플랫폼의 레거시 비디오 추상화 계층일 가능성을 강하게 시사합니다. 네이티브
NVIDIA GOP로 확인된 것은 아닙니다. 그 아래에 NVIDIA 레거시 ROM 서비스가
있을 수 있으며 NVIDIA 문자열이 없다는 사실로 이를 배제할 수 없습니다.

GOP 자식에서는 두 번째 에이전트가 Simple Text Output
(`387477c2-69c7-11d2-8e39-00a0c969723b`)을 `BY_DRIVER`로 열고 시스템
콘솔 핸들에 대해 `BY_CHILD_CONTROLLER`로 엽니다. 해당 바인딩은 `IMG14.BIN`에
연결됩니다. 따라서 PCI-to-GOP 소유자 위에 텍스트 콘솔 계층이 존재합니다.
그래프에는 다른 소비자도 있으므로 연결 하나를 제거해도 전체 장치나 콘솔이
해제되었다고 입증할 수 없습니다.

이미지 스냅샷은 32개이며 고유 SHA-256 값은 25개입니다. 여러 바인딩이 같은
로드된 이미지를 사용하는 경우 중복 스냅샷이 생길 수 있습니다. 이 파일들은
메모리에 로드된 이미지이며 원본 PE 파일이나 ROM 내용과 같다고 보장할 수
없습니다. null 이미지 바인딩 및 드라이버 바인딩 없는 이미지는 이 수집 방식에
포함되지 않습니다. 전체 펌웨어 수집을 주장하지 않습니다.

## 오프라인 재현

```powershell
python research/profile/analyze-ownership.py C:\private\capture\RTX3090-UNLOCK `
  --output C:\private\ownership.json
python -m unittest discover -s research/profile -p 'test_*.py'
```

분석기는 중복 핸들/이미지 인덱스, 이미지 길이 불일치, 누락되거나 모호한 AD104
대상을 거부합니다. 이미지 실행, 드라이버 해제 또는 트랜잭션 허용은 수행하지
않습니다. 해시는 재배치된 특정 스냅샷을 식별하며 범용 공급업체 펌웨어 버전을
식별하는 값이 아닙니다.

## 캡처 변경과 다음 실험

AD104 진단은 허용 조건 검사 전에 읽은 PCI command 비트를 출력합니다.
버스 마스터링 비활성화 조건은 유지됩니다. RAM 전용 테스트는 BME 활성화 시
레지스터/PROM 읽기가 0회임을 명시적으로 확인합니다. 현재 검사는 AD104 151개,
MBR 66개, GPT 4개, 거부된 컴파일 조합 16개, Python 테스트 15개입니다.
첫 실제 캡처는 이전 빌드의 결과입니다. 이번 분석을 위해 새 EFI를 빌드하거나
USB에 복사하거나 부팅하지 않았습니다.

동일한 부팅을 반복할 필요는 없습니다. BME 거부 원인은 이미 설명되었습니다.
다음 캡처 설계에서는 레거시 비디오/CSM 프로토콜 존재 여부와 제한된 구성 요소
이름을 기록하고 펌웨어 제공 PCI I/O `RomImage`/`RomSize` 메타데이터를
기록하는 것입니다. 제한된 형식 검사와 전용 테스트 후에만 해당 펌웨어 메모리
버퍼 복사를 검토합니다. BAR MMIO, command 비트 쓰기 또는 드라이버 해제 없이
ROM 증거를 얻을 가능성이 있지만, 버퍼 제공 여부와 실제 PROM과의 동일성은
알 수 없습니다. 이는 제안이며 구현된 캡처나 기존 보호 조건 우회 승인이
아닙니다. 완전한 PROM/레지스터 캡처 및 언락은 아직 막혀 있습니다.
