# 세 번째 AD104 테스트: 제한된 펌웨어 ROM 버퍼 캡처

[English](AD104-THIRD-BOOT.en.md) | 한국어

두 번째 부팅에서는 null이 아닌 PCI I/O ROM 버퍼와 `0x24a00`(150,016)바이트를
보고했습니다. 이번 테스트는 해당 펌웨어 제공 버퍼를 일관되게 읽을 수 있는지,
첫 옵션 ROM/PCIR 헤더가 제한 범위 안에서 `10de:2782`에 일치하는지 확인합니다.
GPU BAR를 통해 물리 PROM을 읽거나 언락 지원을 입증하지 않습니다.

빌드 옵션: `-Ad104Msi -Ad104Metadata -Ad104FirmwareRom -WindowsMbr`.
출력: `internal-boot/boot/build/probe-ad104-firmrom/BOOTX64.EFI`.
구현 커밋 `e0b91bf`, 24,064바이트, SHA-256:
`45be1100b3042d980e56da1c7553842537b302157117d92dac1585953d2dfe53`.
네이티브 AMD64 EFI PE 검증을 통과했습니다. imports/IAT/delay imports가 없고
NX와 dynamic base가 활성화되어 있습니다. 이 산출물의 실제 실행은 아직 검증하지
않았습니다.

## 허용 조건과 예상 결과

정확한 PCI/서브시스템/리비전 및 NVIDIA 디스플레이 대상 하나를 요구합니다.
버퍼 크기는 두 번째 부팅의 관찰값과 같아야 합니다. 전체 포인터 범위가 최대
64 KiB의 유효한 메모리 맵에서 하나의 Loader/Boot Services RAM 설명자 안에
있어야 하며 runtime 또는 읽기 보호 속성이 없어야 합니다. 예약 영역, MMIO,
중복/분할/잘못된/부족한 매핑은 ROM 포인터를 읽기 전에 거부합니다. 레거시
펌웨어 구조에서는 이 조건으로 캡처가 막힐 수 있습니다. 이는 유용한 거부
결과이며 메모리 조건을 약화할 근거가 아닙니다.

장치 핸들/프로토콜, BDF, PCI 구성 256바이트 전체 및 ROM 포인터/크기를 다시
확인합니다. 복사본에 AA55와 범위 안의 PCIR 헤더, 예상 공급업체/장치 ID 및
유효한 첫 헤더 길이가 있어야 합니다. 두 번째 메모리 맵 검사와 바이트 비교로
일관성을 확인합니다. 이는 원자적 스냅샷이나 임의의 펌웨어 버그에 대한 보장이
아닙니다.

전체 길이 쓰기, flush 및 close가 모두 성공해야
`firmware-rom-buffer dump=FIRMROM.BIN ... sha256=... unlock-eligibility=0`
기록을 남깁니다. 기존 덤프는 거부합니다. 실패 시 `firmrom-*` 원인을 확인합니다.
성공 기록과 일치하는 해시가 없는 부분 파일은 인정하지 않습니다. ROM 바이트를
실행하지 않으며 BME를 그대로 유지하고 GPU MMIO 메서드도 호출하지 않습니다.

`capture-complete=0`과 최종 `EFI_NOT_READY`는 의도된 결과입니다. 완전한
프로필에 필요한 GPU 레지스터/PROM 증거를 수집하는 모드가 아니기 때문입니다.
성공한 `FIRMROM.BIN`도 펌웨어 버퍼일 뿐 완전한 물리 ROM이나 검증된 펌웨어
트랜잭션을 입증하지 않습니다.

호스트 검사 통과: 펌웨어 버퍼 113개, 심층 AD104 151개, 메타데이터 24개,
MBR 66개, GPT 4개, 거부된 컴파일 조합 18개, Python 테스트 15개입니다.
읽을 수 없는 포인터, 메모리 조건, 메타데이터/내용 변경, 헤더 범위 및 잘못된
출력 핸들을 검사했습니다.

## 사용자가 현장에 있는 부팅

준비 전에 이전 캡처와 부팅 파일을 보관합니다. 기존 이름을 사용하는 활성
`RTX3090-UNLOCK` 폴더는 비어 있어야 합니다. 디스크 포맷이나 BootOrder 변경은
필요하지 않습니다. 작업을 저장하고 캡처 USB를 연결한 채 `shutdown /s /t 0`을
실행합니다. 완전히 꺼진 뒤 10초 기다립니다. 전원을 켜고 Delete로 ASUS BIOS에
들어간 다음 F8에서 8GB USB DISK 2.0의 UEFI 항목을 선택합니다. 테스트 키 입력은
필요하지 않습니다. 이후 고정된 Windows 로더 시작을 시도합니다.

4분 안에 Windows로 복귀하지 않으면 전원을 끄고 USB를 제거한 뒤 일반 Windows
Boot Manager로 부팅합니다. 자동 복귀는 보장하지 않습니다. 복귀 후 다시 부팅하기
전에 새 로그와 덤프 전체를 보존합니다. 원본 펌웨어를 공개하지 마십시오.
거부도 가능한 예상 결과입니다. 같은 이미지를 반복 부팅하거나 BIOS 설정을
변경하여 강제로 통과시키지 마십시오.
