# 일곱 번째 AD104 부팅: EDID 해제 관측

[English](AD104-SEVENTH-RESULT.en.md) | 한국어

2026-10-26 실제 시험에서 정확히 지정한 EDID 연결 해제를 한 번 완료했다.
실제 키보드 입력 확인 두 번, 사후 수집 두 번 및 최종 사후 검사를 포함한
모든 실험 단계가 성공을 반환했다.

| 관측 | 이전 | 이후 |
| --- | --- | --- |
| 관련 활성 관계 | 8 | 7; EDID 관계 없음 |
| IMG08 공유 바이트 | 1 | 0 |
| 두 포인터 카운트 | 1 / 1 | 1 / 1 |
| 장치 속성 | `718` | `718` |
| 지원 속성 | `1b77b` | `1b77b` |
| PCI command | `0007` | `0007` |

기록한 네 개의 256바이트 PCI 구성(initial, post, post-repeat, final-post)은
모두 동일하다. 정확한 사후 상태 검사기는 고정한 코드/바인딩, 남은 관계,
BAR 설명자와 콘솔/입력 식별 정보도 통과시켰다. 대문자 `V` 입력 성공으로
연결 해제 후 키보드 입력을 확인했다. 포인터 이동은 시험하지 않았다. 포인터
관계와 카운트의 일치만으로 실제 이동을 입증할 수는 없다.

사용자는 EFI 테스트가 종료되면 Windows 부팅이 시작된다고 명시적으로 보고했다.
이후 Windows의 `nvidia-smi` 조회는 `00000000:0B:00.0`의 RTX 4070 Ti,
드라이버 `610.88`, VBIOS `95.04.31.00.f0`를 확인했다. 이번 실행에서 Windows
복귀와 드라이버 사용 가능성을 뒷받침한다. 로그는 Windows 시작 허용 상태를
기록하며 StartImage 이후의 추적은 아니다. 일반적인 복구 신뢰성이나 다른
드라이버 해제 후의 동작을 입증하지는 않는다.

33개 파일을 새 비공개 호스트 폴더에 보존했고 각 USB/복사본의 SHA-256이 일치했다.
로그는 400,491바이트이며 SHA-256은
`3746cbe874eb563a6e1fe824b2afc1283f7fd6307216fc75745b2cee9ae764ab`이다.
USB EFI도 준비한 SHA-256과 일치한다.
`5503b5fc3cda5cac2d9bc852d669ec509890f94800a205510da54b099b9d69f7`.
[정리된 증거](ad104-seventh-boot-evidence.json)를 참고한다. 원본 펌웨어는 비공개로
유지하며 분석 중 USB 원본과 설치된 EFI를 변경하지 않았다.

이번 펌웨어에서 예상한 EDID 수명 주기 전이를 검증했다. PCI 소유자 해제,
cold-entry 증거 또는 unlock은 아니다. BME는 켜져 있으며 GPU MMIO, 속성 쓰기,
unlock 트랜잭션은 실행하지 않았다. 앞부분의 `capture-complete=0` 및
`EFI_NOT_READY`는 메타데이터 기준 수집의 결과다. 이후 실험 성공은 별도 결과다.

다음 후보는 IMG17 GOP 소비자보다 앞선 IMG14 텍스트 바인딩이다. 추가 오프라인
분석과 별도 실험 계약이 필요하다. Stop의 초기 분석에서 자식에 따른 정리,
CloseProtocol 호출 및 메모리 해제가 보인다. 자식 수가 0일 때의 성공 반환만으로
해제를 입증할 수는 없다. 텍스트 관계 해제는 화면 안내를 무효화할 수 있어 현재의
사후 입력 안내 경로를 그대로 재사용하면 안 된다. 다음 EFI 테스트는 준비하지
않았으며 성공한 EDID 테스트를 반복할 필요도 없다.
