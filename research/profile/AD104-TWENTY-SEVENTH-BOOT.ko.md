# 스물일곱 번째 후보: GSP 기능 및 상태 관측

[English](AD104-TWENTY-SEVENTH-BOOT.en.md) | [한국어](AD104-TWENTY-SEVENTH-BOOT.ko.md)

검토용 빌드/호스트 검사 완료, 사용자가 새 MMIO 위험과 이 후보의 스테이징을 명시적으로 승인했습니다. 실제 테스트27은 성공적으로 완료됐으며 검증된 스테이징 전에 테스트26 원본/기존 EFI를 보존합니다. 성공한 메일박스 기준 상태에 공개된 읽기 전용 주소3개를 추가하고 DMACTL은 제외합니다.

11회씩 두 배치:
`0, 0x110100, 0x110040, 0x110044, 0x110008, 0x1100f4, 0x110108, 0x82381c, 0x823820, 0x625f04, 0`.
새 주소는 GSP IRQSTAT0x110008, HWCFG2=0x1100f4, HWCFG=0x110108입니다. [NVIDIA 정의](https://github.com/NVIDIA/open-gpu-kernel-modules/blob/main/src/common/inc/swref/published/ampere/ga102/dev_falcon_v4.h)는+8/+f4/+108을 읽기 전용으로 명시하며 GSP 기준 주소는0x110000입니다. Ampere 정의가 AD104 접근 안전성을 보장하지 않습니다.

원본 값, HWCFG2 RISCV비트10/메모리 스크러빙 비트12 및 HWCFG IMEM 크기 필드8:0을 기록합니다. 기능 비트로 현재 CPU 모드를 추론하거나 단위 검증 없이 크기를 바이트로 환산하지 않습니다.0/안정된 값은 유휴/준비/인증 증거가 아닙니다. 새 필드의 배치 간 변화는 거부하지 않습니다. 펌웨어 실행 설계 전에 인터페이스를 관측하며 장치 진입 검사를 우회하지 않습니다.

기존 칩/CPUCTL/SS0/SS1/VGA 일치, 모두1/BADF, 전송/메서드/소유권/입력/PCI/로그 검사를 유지합니다. RAM 읽기 중 파일/콘솔/할당 콜백은 없습니다. 로그 전/사이/후 전체 상태를 재검증하며 한 번만 시도합니다. 실패하면 디코딩이 켜진 상태로 영구 정지할 수 있고 Windows 대체 복귀는 없습니다.

성공 시 추가 읽기는26의16회에서22회(전체262342회)이며 새 주소3개를 각각 두 번 읽습니다. GPU 쓰기/리셋/인터럽트 확인/DMA 시작/BME·VGA 활성화/펌웨어 업로드·실행/재연결/언락/자동 롤백은 추가하지 않습니다. 새 읽기는 부작용/정지를 일으킬 수 있고 화면/입력/Windows 실패와 수동 전원 차단/USB 제거가 필요할 수 있습니다. 복구는 미검증이며 이 스테이징 경계의 명시적 승인을 받았습니다.

호스트는25/26/27 모드,22개 전송 오류 위치, 새 레지스터별 모두1/BADF, 기존 상태/메서드/소유권/로그 오류와 IRQ/HWCFG 변화 허용을 검사합니다. AMD64/가져오기 없음 EFI67,072바이트, SHA256:
`c945a05fadc7fa86f5aca5bf7ea8f8464dd4703326489d13130872620ffeeecb`.
기능 관측=true, 추가읽기22, DMACTL/펌웨어실행/언락=false입니다.

## 기존 샘플의 오프라인 배치 해석

추가 하드웨어 접근 없이 계산했습니다. vendor/unlock_610.c에서 usableFB=0x2ffa00000, 원본 VGA=0x10e0000은 usableFB-1MiB보다 작으므로 기존 정책은 usableFB-128KiB=0x2ff9e0000을 선택합니다. MMU low=0x10000000, high=0x2ef9ff000, 반올림 배타 상단=0x2efa00000은 usableFB보다 정확히256MiB 낮습니다. 해당 코드의 top_lock은 false이며 framebuffer 최상단 예약으로 취급하지 않습니다. 기존 알고리즘 계산 결과일 뿐 AD104 적용 승인이나 유효 배치 증거가 아닙니다. 자산/실제 할당·예약/겹침·스크럽 제약 및 진입 정책을 검증해야 합니다. 계산한 주소를 하드웨어에 쓰지 않으며 전체 트랜잭션 배치가 유효하다고 주장하지 않습니다. 체크리스트15/26(58%) 유지입니다.

검증된 스테이징 후 작업 저장/완전 종료/10초/UEFIUSB/Shift+G 한 번.10초 후 Shift+V를2초마다 최대3분 누릅니다.10분 후 Windows가 없으면 전원 차단/USB 제거/정상 Boot Manager를 선택합니다. 보호 정지는 키로 재개할 수 없습니다. 한 번만 실행하고 캡처를 보존하며 복구는 미검증입니다.
