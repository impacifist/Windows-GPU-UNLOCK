# 세 번째 AD104 부팅: 펌웨어 ROM 버퍼 캡처 성공

[English](AD104-THIRD-RESULT.en.md) | 한국어

2026-10-26의 세 번째 진단에서 150,016바이트의 `FIRMROM.BIN`을 저장했습니다.
SHA-256은 `0ec450dce01cfc8f8b599b165f2de00c0fc6e2d2683c1be491251078c6a3a9fd`이며
진단의 전체 쓰기/flush/close 성공 기록과 일치합니다. 캡처 파일 34개를 별도의
비공개 호스트 보관 위치로 복사하고 각 SHA-256이 USB 원본과 일치함을 확인했습니다.
USB 원본은 변경하지 않았으며 원본 ROM 버퍼는 Git에서 제외합니다.

로그는 ROM 포인터 존재, 크기 `0x24a00`, PCI command `0007`(메모리 디코딩과
버스 마스터링 활성화)을 보고합니다. 허용된 RAM 버퍼 캡처 경로가 GPU MMIO,
BME 변경 또는 드라이버 해제 없이 성공했습니다. `unlock-eligibility=0`,
`capture-complete=0`, 최종 `EFI_NOT_READY`는 의도된 결과입니다. 펌웨어 버퍼
복사 성공이 완전한 GPU 프로필을 뜻하지는 않습니다.

초기 오프라인 헤더 검사에서 AA55, 오프셋 368의 PCIR, 공급업체 `10de`, 장치
`2782`, PCIR 길이 24, 첫 이미지 길이 64,512바이트, 코드 유형 0, indicator 0을
확인했습니다. 따라서 첫 이미지는 체인의 마지막으로 표시되지 않습니다. 첫 헤더
검사만으로 후속 이미지나 전체 체인의 유효성을 판단할 수 없습니다. 버퍼가 완전한
물리 ROM 내용인지도 아직 입증되지 않았습니다.

진단 로그는 395,912바이트입니다. 소유권 분석은 수집된 PCI-to-GOP 소유자와
텍스트 콘솔 관계를 다시 확인했습니다. 로그는 여전히 Windows 시작 호출 전에
끝나므로 사용자의 복귀만으로 해당 자동 인계 경로가 입증되는 것은 아닙니다.

다음 작업은 전체 옵션 ROM 이미지 체인의 범위, 이미지 유형 및 체크섬을 오프라인으로
검증하고 EFI 이미지가 있다면 관찰된 레거시 비디오 소유권 경로와 비교하는 것입니다.
추출한 이미지를 실행하거나 원본 펌웨어를 공개하지 않습니다. 새 EFI를 준비하지
않았으며 이 오프라인 분석을 위해 다시 부팅할 필요는 없습니다. 언락은 아직
입증되지 않았습니다.
