# 호환성 보고 분류

[English](COMPATIBILITY-TRIAGE.en.md) | **한국어**

[호환성 양식](https://github.com/impacifist/Windows-GPU-UNLOCK/issues/new?template=compatibility.yml)과 [기여 안내](CONTRIBUTING.ko.md)를 사용합니다. 인벤토리만 제출해도 됩니다. 기존 증거를 요청하되, 접수 항목을 채우기 위해 부팅하거나 펌웨어 설정을 바꾸거나 실패한 실험을 반복하도록 요구하지 않습니다.

## 검토 순서

1. 기존 이슈와 PR을 검색합니다. 중복으로 판단하기 전에 보고자, 실제 GPU, 보드/BIOS, 소스/빌드, 화면 연결 경로를 비교합니다. 관련 사례를 연결하고 원래 증거를 보존하며 설정 또는 빌드 변경을 명시합니다.
2. 알려진 정확한 보드/CPU/GPU, 보고된 PCI/서브시스템 ID, BIOS, Windows/드라이버 버전과 실제 모니터 연결을 기록합니다. 실제 카드와 소프트웨어 식별 정보 또는 교차 플래시된 VBIOS를 구분합니다. 모르는 값은 미상으로 남깁니다.
3. 기존 실행의 각 캡처를 소스 리비전/로컬 변경, 생성한 프로필, EFI SHA-256, 빌드 명령/옵션, 컴파일러에 연결합니다. 개인정보를 제거한 발췌문이나 해시를 요청하며 펌웨어 자산, PROM/IMG 덤프, 개인 시스템 보고서는 요청하지 않습니다.
4. 운영자가 관찰한 Windows 결과를 별도로 기록합니다. 정상 화면으로 직접 진입했는지, 화면 복구 조작이나 수동 전원 재시작이 필요했는지, 실패했는지, 미상인지 구분합니다. 로그 종료 표시는 이 항목의 근거가 아닙니다.
5. 성능 측정은 별도로 검토합니다. 정밀도/누산 방식, 행렬 크기, 라이브러리/드라이버 버전, 실행 횟수, 부팅 수명주기가 일치해야 합니다. 트랜잭션 성공은 성능 향상의 증거가 아닙니다.

## 증거 상태 구분

| 상태 | 확인되는 내용 | 아직 입증되지 않은 내용 |
|---|---|---|
| 보고 접수 | 기여자가 관찰 결과를 제출함 | 캡처 유효성 및 지원 여부 |
| 캡처 검증 | 검토한 캡처 및 식별/빌드 관계가 해당 검사기를 통과함 | 하드웨어 트랜잭션 및 Windows 복구 |
| 트랜잭션 보고 | 기존 로그에 트랜잭션/정리 결과가 기록됨 | 독립적인 적격성 검토, Windows 결과 및 성능 |
| Windows 결과 보고 | 운영자가 실제 인계/화면 결과를 설명함 | 일반적인 호환성 및 측정된 향상 |
| 하드웨어 적격성 확인 | 관리자가 프로젝트 요건에 따라 정확한 구성을 승인함 | 다른 머신, 펌웨어 버전 또는 화면 경로 |

이는 검토 설명이며 자동 라벨이나 순차적인 성공 점수가 아닙니다. 호스트 검사가 통과해도 하드웨어는 실패할 수 있습니다. [검증 기록](VALIDATION.ko.md)에 각 결과와 출처를 별도로 기록합니다. 기존 지원을 주장하기 전에 [호환성 표](COMPATIBILITY.ko.md)와 [확인된 구성 증거](CONFIRMED-SETUPS.ko.md)를 참조합니다.

## 후속 요청 및 해결

누락된 정보는 한 번의 구체적인 요청으로 묶습니다. 각 항목을 설명할 기존 파일이나 관찰 내용을 명시하고, 증거를 구할 수 없다는 답도 인정합니다. 실패와 상충하는 결과를 유지합니다. 이후 성공한 실행은 이전 결과를 덮어쓰지 말고 변경된 빌드/설정을 밝혀야 합니다.

지원되는 LOCAL 구성이라면 새 하드코딩 보드 프로필 대신 소유자가 생성하는 비공개 프로필이 필요한지 설명합니다. 다른 머신의 주소, 해시, 소유권 고정값을 복사하지 않습니다. 런타임 허용 범위 확대나 새로운 하드웨어 적격성 확인은 코어 담당자 검토가 필요합니다.

PR이 해당 이슈의 요청을 실제로 해결할 때만 `Resolves #123` 같은 종료 키워드를 사용합니다. 보고를 확인하거나 표에 추가하는 것만으로 미해결 실패가 해결되지는 않습니다. 부분 작업에는 종료하지 않는 참조를 사용합니다. 병합 전에 GitHub의 연결된 이슈를 확인합니다. 설명 중의 `Closed #123` 같은 표현도 종료 키워드로 해석될 수 있습니다. 검토 라벨은 작업 유형을 나타내며 지원 인증이 아닙니다.

이 안내는 접수와 증거 처리 절차입니다. 관리자 적격성 정책을 대체하거나 하드웨어 실행을 허가하지 않습니다.
